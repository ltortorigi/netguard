How to read this page

Responding means the public entry point returned HTTP 2xx or 3xx. Check failed means this monitor encountered an error; it is not confirmation of a campus-wide outage. Restricted means authentication or rate limiting prevented a useful check. Unknown and stale results are not shown as healthy.

Three public entry points are checked every five minutes, with a five-second deadline and no login or redirect following. Email and campus Wi-Fi use reports only. No checks run against internal UNA networks.

Report a problem

Share a problem category only. No name, password, or student information is collected.

One report per system per network address in each 15-minute window. Shared campus networks may be counted together. A keyed hash prevents duplicates; raw IP addresses are not saved in reports.
